希臘古神 WebAR V0.2 — Windows 操作
1. 解壓縮。保留原有 assets 及 index.html；新增 ar 資料夾。
2. 開啟 https://hiukim.github.io/mind-ar-js-doc/tools/compile/ ，選擇 ar/targets 內 00 至 12 的 JPG，務必依檔名前綴順序確認預覽。Start → Download compiled，改名 gods.mind，放入 ar/targets/。若編譯器順序不同，請重新排列或調整 gods.json 的 index。
3. 備份 GitHub 原版，將 index.html 和整個 ar 資料夾上傳到原本 Repository 根目錄。等待 Pages 部署。QR 已指向 https://700-yrs.github.io/greek-mythology-origins/ar/ 。
4. 電腦播放前導片至結束，掃描 QR；電腦按 START，手機按開啟相機，允許權限，對準角色左半部。iPhone Safari、Android Chrome 分別測試。
5. 辨識圖為原素材及背景依網站定位合成，未包含瀏覽器色調混合與陰影，並非實際截圖。若辨識不穩，使用 1670×941 的實際網站畫面截取 x=0,y=35,w=780,h=850 的區域替換對應 JPG，重新編譯。避免改變網站美術。
6. 目前為 PNG 程式控制的 2.5D 浮出動畫，非正式角色影片；原前導片未修改。未提供 gods.mind，未實測手機；需網路載入 CDN。若掃描不穩，先測宙斯再擴充。QR 在跳過或播放失敗時也會出現。
